# Download recovery contract

Samsung remains the owner of downloaded audio. A playlist save skips committed files, runs at most four transfers, and publishes completion only after the file commit. OnePlus renders Samsung's existing status fields. Existing download names, inputs, files and LAN fields remain readable.

The user authorized token-backed extraction and controlled client fallback after comparing Metrolist. NativeAudioSource remains the sole source strategy. Its existing NewPipe path stays first; a failed anonymous public-stream extraction may use a maintained JavaScript resolver with web Proof-of-Origin attestation. Explicit private, age, membership, geographic, DRM and sign-in refusals remain failures. No account cookies, OAuth tokens, replacement uploads, transcoding or second player are introduced.

The JavaScript libraries are pinned, MIT-licensed dependencies bundled as an APK asset, because Metrolist's current Kotlin library requires a toolchain migration. Their source is not copied into Kotlin. The WebView runs attestation and extraction only, with no media playback or UI; application context, a serialized operation, bounded HTTPS-only native requests and a deadline own its lifetime. Each operation destroys its renderer and retains no tokens, cookies, URLs or browser storage. Failure and cancellation release the renderer and transfer permit. Only safe error codes enter logs.

Acceptance: previously failing public IDs are retried on the physical Samsung; existing saved files remain byte-identical; header/rows show committed downloads; unavailable songs finish as failed without blocking the rest. JVM regressions cover trusted URLs, invalid outputs, failure classification, bounded refresh, cancellation and file preservation. Physical token/renderer and process-restoration results must be reported separately from unit checks.

No claim is made that every YouTube upload is anonymously accessible. Public metadata alone does not establish downloadable availability.
