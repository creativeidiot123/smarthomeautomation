# m3-expressive

Destination's primary Material Design 3 / M3 Expressive agent skill.

The local bundle is intentionally **text-only**:
- `SKILL.md` is the entry point and routing guide.
- `references/` contains the upstream Markdown knowledge base.
- `SOURCE.md` records provenance and links to upstream visual/example material.
- `LICENSE` and `NOTICE.md` preserve attribution and licensing context.

Binary media, the large visual caption index, and refresh scripts are not copied into Destination.
