# Visual reference library

Destination does **not** vendor the upstream M3 image library. The text references remain local, while
visual anatomy diagrams, measurements, state grids, do/don't pairs, and complete UI examples stay in
the source repository.

Use these pinned upstream links:

- [Full visual library](https://github.com/abhixv/m3-expressive-design-skill/tree/70ff9dcecd2cf04660109b4e4a89205a2dacd290/skills/m3-expressive/visuals)
- [Caption index for all upstream visuals](https://github.com/abhixv/m3-expressive-design-skill/blob/70ff9dcecd2cf04660109b4e4a89205a2dacd290/skills/m3-expressive/visuals/INDEX.tsv)
- [Canonical full-screen layout examples](https://github.com/abhixv/m3-expressive-design-skill/tree/70ff9dcecd2cf04660109b4e4a89205a2dacd290/skills/m3-expressive/visuals/foundations_layout_canonical-examples)
- [Layout overview and responsive examples](https://github.com/abhixv/m3-expressive-design-skill/tree/70ff9dcecd2cf04660109b4e4a89205a2dacd290/skills/m3-expressive/visuals/foundations_layout_layout-overview)

The upstream library contains official Material reference images captured from m3.material.io. Treat
the local Markdown token/component references as the source for exact values; use images to understand
composition and verify ambiguous visual guidance. Do not infer dp/sp values by measuring pixels.

If the skill is refreshed to a newer upstream commit, update these links and `SOURCE.md` together so
the text and visual examples stay on the same snapshot.
